# Shorts automation

Daily production for two original commentary channels: 오늘의 오지랖 (Korean) and A Not-So-Polite Korean (English, a Korean perspective).

Target: four distinct topics per day, two videos per channel. Research must cite current reporting; commentary must be identified as opinion. Only approved reusable footage is included.

This repository is being configured. Cloud production and publishing are not yet active. Credentials must be stored exclusively in GitHub Actions secrets, never in repository files.
