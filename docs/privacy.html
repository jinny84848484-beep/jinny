Privacy and data handling

Updated November 5, 2026. This is a personal tool for its owner's YouTube channels, not a public service accepting other users.

Data used

The application uses the authorized channel identifier, video metadata and public statistics to verify upload destinations and track the owner's published videos. It requests YouTube upload and read-only scopes. It does not request Gmail, Google Drive, contacts or payment access.

Storage and processors

OAuth credentials are stored using Windows DPAPI on the owner's PC and encrypted GitHub Actions Secrets for cloud execution. Credentials are excluded from the public source repository and production logs. GitHub hosts the scheduled production workflow. OpenAI processes public news and editorial prompts, and ElevenLabs processes narration text. OAuth credentials are not included in those prompts. Public publication records are stored in the project repository. Workflow media artifacts are retained for seven days.

Owner control

The owner can disable scheduled workflows, remove Actions secrets and revoke the application's permissions through Google account connections. Revocation prevents further authorized access. Removing authorization does not delete videos already published to YouTube; those remain under the owner's control in YouTube Studio.
