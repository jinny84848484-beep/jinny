# 방구석 세계요리 비공개 렌더 및 검수 준비

명령 하나로 기존 레시피 렌더를 실행한 후 정확한 세로 MP4, 자막, 설명 및 렌더 결과 지문을 대조한다. 리눅스 작업공간의 승인된 비공개 경로 전용이다. API·계정·게시 권한·자동 예약은 사용하지 않는다. 공개 GitHub 큐와 오후 5시 빈 큐 확인은 변경하지 않는다.

## 사용

1. 저장소 바깥의 실제 비공개 작업공간에 서로 다른 소유자 전용 디렉터리 두 개를 준비한다. 예: `install -d -m 700 /private/path/input /private/path/output`. 공유 링크·공개 저장소·공개 runner가 아니어야 한다.
2. 입력에 `queue.json`을 둔다. 예: `[{"date":"2026-11-21","reviewed":true,"manifest":"recipe.json"}]`. 레시피 JSON과 로고·생성/권리 검토된 사진·나레이션·선택 배경음은 입력 루트 기준 상대경로로 지정한다. 그림 PNG/JPEG/WebP, 오디오 WAV/MP3/M4A만 받는다. URL, 심볼릭 링크, 외부 경로, 플레이리스트는 사용하지 않는다. 레시피의 검수 표시가 실제 사용권 또는 사람 검수를 대신하지 않는다.
3. 코드 체크아웃에서 실행한다.

```sh
python -m world_kitchen.private_render_check \
  --private-input /private/path/input --private-output /private/path/output \
  --date 2026-11-21
```

시작 시 날짜별 시도 폴더를 원자적으로 만든다. 동일 날짜는 실패 후에도 자동 재실행하지 않고 기존 폴더나 영상을 덮어쓰지 않는다. 출력은 `output/YYYY-MM-DD/`; 작업본과 상태는 `output/.attempts/YYYY-MM-DD/`에 비공개로 남는다. 오류가 나면 로컬 작업 상태와 남은 파일을 확인하고 원인을 해결한다. 기록을 삭제해서 재시도하면 안 된다.

`source_manifest_sha256`은 입력에서 읽은 원본 JSON 내용, `staged_manifest_sha256`(또는 `manifest_sha256`)는 렌더러가 읽고 출력 검증기가 다시 읽은 경로 재작성본의 내용이다. 읽은 입력 미디어를 시도별 경로에 복사하고 음성 데먹서와 허용 프로토콜을 고정한다. 결과에는 파일 지문만 나오며, 최종 영상·음성·고정 엔딩·자막·안전·권리의 독립적인 검수가 **아직 필요**하다. 신뢰 승인, 실제 업로드 또는 19시 예약을 뜻하지 않는다. 이 명령은 그 작업을 수행할 기능이 없다.
